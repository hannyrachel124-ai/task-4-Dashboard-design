# Task 4 – Interactive Sales Dashboard

## Overview

Created an interactive sales dashboard using **Power BI** to analyze sales, profit, segments, countries, discounts, and time-based trends.

## Tools Used

* Power BI
* Excel
* PowerPoint

## Key Insights

* Paseo generated the highest profit (~$4.8M).
* Government was the largest sales segment (~$52.5M).
* USA recorded the highest sales.
* October had the highest monthly sales.
* Sales increased significantly from 2013 to 2014.

## Deliverables

* Interactive Power BI Dashboard
* PPT Summary
